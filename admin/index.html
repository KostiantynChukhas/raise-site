Word catalog

Pick a pack on the left. Edit any cell, add or delete words, then Publish changes — the admin commits the JSON straight to GitHub, bumps the pack version and rebuilds manifest.json. The app picks up the new version on its next sync. No server needed.

First time: open Settings and paste a GitHub token (fine-grained, Contents: read & write on this repo). Optionally add an Anthropic API key to translate new words automatically.

Tip: the app shows a word for a language pair only when both languages are filled. Keep strings short (≤ 60 chars) — they're rendered on a watch face.
